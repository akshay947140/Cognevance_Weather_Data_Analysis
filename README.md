# Weather Data Analysis

Analyze weather datasets using Python to identify temperature, humidity, and seasonal trends.

## Project Structure

```
weather_project/
├── data/
│   ├── weather_raw.csv          # raw dataset (with intentional data quality issues)
│   ├── weather_clean.csv        # cleaned dataset (730 daily records)
│   └── monthly_summary.csv      # monthly aggregated statistics
├── charts/
│   ├── 01_monthly_avg_temperature.png
│   ├── 02_monthly_avg_humidity.png
│   ├── 03_monthly_total_rainfall.png
│   ├── 04_seasonal_temperature_boxplot.png
│   ├── 05_temp_vs_humidity_scatter.png
│   └── 06_correlation_heatmap.png
├── src/
│   ├── generate_dataset.py      # generates the raw dataset
│   └── clean_analyze.py         # cleaning, analysis, and chart generation
├── Weather_Data_Analysis_Report.docx
├── requirements.txt
└── README.md
```

## About the dataset

This project ships with a **synthetic** 2-year daily weather dataset (2023–2024) generated by `src/generate_dataset.py`. It follows realistic seasonal patterns (temperature, humidity, rainfall) and deliberately includes the kinds of problems real downloaded datasets have — missing values, duplicate rows, and impossible sensor readings — so the cleaning step has real work to do.

**To use a real dataset instead** (e.g. from Kaggle):
1. Download a daily weather CSV, for example:
   - [Kaggle: Weather Dataset](https://www.kaggle.com/datasets/muthuj7/weather-dataset)
   - [Kaggle: Historical Hourly Weather Data](https://www.kaggle.com/datasets/selfishgene/historical-hourly-weather-data)
   - Or your national meteorological service / NOAA archives
2. Save it as `data/weather_raw.csv` with (at minimum) `date`, `temperature`, `humidity`, and `rainfall` columns — rename columns in `clean_analyze.py` to match.
3. Skip `generate_dataset.py` and run `clean_analyze.py` directly.

## How to run

```bash
pip install -r requirements.txt
cd src
python3 generate_dataset.py   # only if you don't have your own dataset
python3 clean_analyze.py
```

This produces the cleaned dataset, monthly summary CSV, and 6 chart PNGs.
